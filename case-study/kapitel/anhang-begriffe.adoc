== Begriffe

[glossary]
ADR:: Architecture Decision Record. Eine kurz begründete Entscheidung mit den betrachteten Optionen und ihren Folgen, gesammelt in Anhang A.
Decision-Modell:: Ein Sprachmodell, das aus einer festen Liste von Optionen genau eine wählt und dazu angibt, wie sicher es ist. MANUEL nutzt `d3:9b`.
Embedding:: Eine Zahlenfolge, die die Bedeutung eines Textes abbildet. Ähnliche Texte liegen nah beieinander, so findet die Ähnlichkeitssuche passende Kategorien.
Harness:: Alles, was ein Modell umgibt, also Auftrag, Kontext, Werkzeuge und die Prüfung der Antwort. Bei MANUEL etwa der Ticket Categorizer von Zammad oder die Skripte in `eval/`.
Inferenz:: Das Ausführen eines fertigen Modells, um eine Antwort zu erzeugen. Engines dafür sind etwa Ollama und llama.cpp.
Kette:: Der Ablauf für Nachrichten. Das Sprachmodell zieht zuerst die Gegenstände heraus, das Decision-Modell ordnet sie dann ein.
Laufzettel:: Ein Formular, auf dem eine Reparatur erfasst wird, auf Papier oder online.
Mixture of Experts:: Ein Sprachmodell, das aus vielen Teilnetzen besteht und für jedes Token nur einige davon nutzt. Es rechnet dadurch schneller, als seine Größe vermuten lässt.
Nachfrage beim Gast:: Eine Frage an den Gast, wenn Angaben fehlen, etwa Alter, Bauart oder Größe des Geräts. MANUEL entwirft den Text, ein Mensch schickt ihn ab.
Open Repair Data Standard:: Das gemeinsame Format der Open Repair Alliance für Reparaturdaten.
ORA-Gruppe:: Eine Produktkategorie des Open Repair Data Standard, etwa Coffee maker für Kaffeemaschinen.
Prompt Injection:: Ein Angriff, bei dem Text von außen, etwa auf einer Webseite, Anweisungen an ein Sprachmodell enthält, die es vom eigentlichen Auftrag abbringen sollen.
Rückfrage:: Eine interne Notiz an das Team. MANUEL macht nummerierte Vorschläge, statt zu raten, etwa wenn nur ein Sammelbegriff wie Kopfhörer genannt ist. Die Engagierten antworten mit der Nummer.
SearXNG:: Eine freie Metasuchmaschine, die Anfragen ohne Konto und ohne Profil an mehrere Suchmaschinen weitergibt. Sie läuft als eigener Dienst.
Sharecard:: Ein Bild mit dem Resümee eines Termins, das sich im Forum, in sozialen Medien und im Messenger teilen lässt.
Sollwert:: Die richtige Antwort für ein Ticket, geprüft durch das Team.
Ticket:: Eine Anfrage in Zammad mit allen Nachrichten und Feldern.
Token:: Ein Stück Text, mit dem ein Sprachmodell rechnet, meist ein Wort oder ein Teil davon. Geschwindigkeiten werden in Token pro Sekunde gemessen.
Trefferquote:: Der Anteil richtiger Antworten an allen Tickets mit Sollwert.
Vertreter-Name:: Der Name, unter dem ein Eintrag des Katalogs dem Modell gezeigt wird, also sein passendster Name oder ein Synonym.
Wilson-Intervall:: Ein Bereich um eine gemessene Quote, der zeigt, wie unsicher sie bei kleinen Zahlen ist. Hier immer mit 95 Prozent Konfidenz.
