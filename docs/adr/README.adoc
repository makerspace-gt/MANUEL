= Entscheidungen

Hier halten wir jede wichtige Entscheidung zu MANUEL als Architecture Decision Record fest, siehe xref:0001-entscheidungen-als-adr-festhalten.adoc[ADR 1]. Die Vorlage folgt MADR auf Deutsch und liegt in xref:vorlage.adoc[vorlage.adoc].

== Regeln

* Eine Datei je Entscheidung, benannt als `NNNN-verbphrase-im-imperativ.adoc`.
* Status ist vorgeschlagen, angenommen, verworfen oder abgelöst durch ein neueres ADR.
* Ein angenommenes ADR wird nicht umgeschrieben. Ändert sich die Entscheidung, entsteht ein neues ADR, und das alte verweist darauf.
* Unter Beteiligte stehen alle, die an der Entscheidung mitgewirkt haben. Bisher arbeitet Michael Prange allein an MANUEL, weitere Mitwirkende kommen bei ihren Entscheidungen dazu.
* Jedes ADR nennt seine Quellen, etwa Messungen in link:../einordnung.md[Einordnung von Tickets] oder link:../benchmarks.md[Benchmarks].
