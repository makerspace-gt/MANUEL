Stick to the following principles:

- Write the defect in German in one short sentence, from the view of the guest, for example "Pumpt kein Wasser mehr, Display zeigt Fehler E3".
- Keep the symptoms and the circumstances the guest names, like when it happens, error codes, noises or smells. Leave out greetings, appointments and anything about the person.
- Do not name the kind of device, brand or model, they have their own fields.
- Do not guess causes. If the guest names a cause as a guess, keep it as such.
- If the ticket names several devices, write the defect of the first one that is to be repaired.
- Leave the field empty when the ticket does not describe a defect.
- Never explain your given answer.
- Only answer with the value in the "problem" field inside the JSON structure.
